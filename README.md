# Syfx Web Library

Pustaka komponen web yang boleh disalin terus. Setiap komponen ada pratonton hidup,
kod HTML/CSS/JS dengan butang salin, dan arahan cara guna.

- 39 komponen dalam satu fail (`index.html`), tanpa library luar
- Kategori: Latar Belakang, Gaya Apple, Asas, Susun atur, Navigasi, Interaktif, Form, Gambar, Galeri, Kreatif
- Cari komen `UBAH:` dalam kod untuk tahu bahagian mana perlu dilaraskan
- Responsif untuk telefon

## Cara guna

Buka `index.html` dalam browser, atau hos percuma guna GitHub Pages
(Settings > Pages > Deploy from a branch > `main` / root).

Ikon tab (`favicon.svg`) ialah SWL hijau ke kuning.

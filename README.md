# Syfx Web Library

Pustaka komponen web yang boleh disalin terus. Setiap komponen ada pratonton hidup,
kod HTML/CSS/JS dengan butang salin, dan arahan cara guna.

- Satu fail (`index.html`), tanpa library luar
- Kategori: Asas, Susun atur, Kreatif, Navigasi, Interaktif, Gambar, Gaya Apple, Form, Galeri
- Responsif untuk telefon

## Cara guna

Buka `index.html` dalam browser, atau hos percuma guna GitHub Pages
(Settings > Pages > Deploy from a branch > `main` / root).
